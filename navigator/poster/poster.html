Which distribution to assume?

What kind of quantity is it?
Yes/No per unit (default, conversion) → Bernoulli / Binomial (Beta-Binomial if the rate varies across groups) fallback: Rate varies by store/branch → Beta-Binomial or hierarchical model
Count of events in a period (units sold, claims)
Compare the variance with the mean.
Variance ≈ mean → Poisson fallback: Over-dispersion → Negative Binomial; varying exposure → rate with offset
Variance ≫ mean (over-dispersed) → Negative Binomial fallback: Many structural zeros → zero-inflated / hurdle
Mostly zeros (intermittent) → see N-FCST-INTERMITTENT
Positive skewed amount (spend, income, claim size) → Lognormal or Gamma (compare Q-Q plots and AIC) fallback: Extreme tail → separate large-loss model / Pareto tail
Time until an event (churn, default) → Exponential (constant hazard) → Weibull (changing hazard); censoring-aware methods fallback: Non-constant hazard → Weibull or Kaplan-Meier
A rate or probability itself → Beta (uncertainty about a probability)
Sample drawn without replacement from a small lot (audit) → Hypergeometric (acceptance sampling) fallback: Small share → Binomial approximation is fine

Which hypothesis test?

Is this an experiment that needs an SRM / design check first?
Yes — randomised test, not yet checked → see N-EXP-SRM
No, or already checked
What type is the outcome?
Continuous (amount, units, score)
How many groups, and are they independent?
2 independent groups → Welch two-sample t-test (+ effect size and CI) fallback: Heavy tails and small n → Mann-Whitney or bootstrap CI
2 paired measurements (same store before/after) → Paired t-test (Wilcoxon signed-rank if differences are skewed) fallback: Skewed differences → Wilcoxon signed-rank
More than 2 groups → One-way ANOVA (+ Levene); Welch ANOVA + Games-Howell if variances differ; Kruskal-Wallis + Dunn if non-normal fallback: Welch ANOVA
2 groups and I have a strong pre-period measure per unit → see N-REG-ANCOVA
Very small samples; I want minimal assumptions → Permutation test
I need to adjust for several covariates → see N-REG-OLS
Binary (rate: default, conversion, return)
How many groups / is it paired?
2 independent groups → Two-proportion z-test (Fisher's exact if any expected cell < 5) fallback: Small counts → Fisher exact
Paired yes/no (same customer before/after) → McNemar's test fallback: Exact binomial on discordant pairs
More than 2 groups or categories → Chi-square test of independence (Fisher exact for small tables) + Cramér's V fallback: Fisher exact or collapse categories
Count / rate with exposure → Poisson / Negative Binomial rate comparison (GLM with exposure offset) fallback: Negative Binomial
Time-to-event with censoring → Kaplan-Meier curves + log-rank test (RMST if hazards cross) fallback: Crossing curves → restricted mean survival time
I am running many tests at once → Multiple-testing correction — Holm (family-wise) or Benjamini-Hochberg (false discovery rate) fallback: Pre-register primary metric; treat the rest as exploratory

Which regression or GLM?

What type is the outcome?
Continuous, roughly symmetric residuals → Linear regression (OLS) with diagnostics fallback: Heteroscedastic → robust SEs or log outcome; outliers → robust/quantile regression; collinear → Ridge
Positive skewed amount → GLM — Poisson/Negative Binomial for counts (offset for exposure), Gamma for positive amounts, Tweedie for zero + positive fallback: Over-dispersion → NB; many zeros → zero-inflated/hurdle or Tweedie
Binary → Logistic regression (odds ratios) fallback: Non-linear → bins/WoE or splines; rare events → penalised (Firth)
Count → GLM — Poisson/Negative Binomial for counts (offset for exposure), Gamma for positive amounts, Tweedie for zero + positive fallback: Over-dispersion → NB; many zeros → zero-inflated/hurdle or Tweedie
Elasticity: % change in units for % change in price → Log-log regression / Poisson GLM on log price (elasticity), with promo, display, SKU, store and week controls fallback: No exogenous price variation → run a price test
Many predictors / signs flip / VIF high → Multicollinearity check (VIF) → drop/combine features or regularise (Ridge, Lasso, Elastic Net) fallback: Combine (e.g. limit/income ratio)
Effect depends on another variable → Interaction terms, splines/polynomials; mixed models for grouped data fallback: Too sparse → bins or regularisation
Risk jumps above a threshold (curved effect) → Non-linear effects — bins/WoE, splines
Insurance pricing: frequency × severity → Frequency-severity GLMs (Poisson/NB × Gamma) or Tweedie pure premium

Which ML model?

What matters most?
Regulator/customer needs reasons for each decision → Logistic scorecard with WoE binning (points to double the odds) fallback: Weak lift → GBM challenger with SHAP under model-risk governance
Best accuracy on tabular data → Gradient boosting (LightGBM/XGBoost) vs logistic/linear baseline; random forest check fallback: Overfitting → stronger regularisation
The target is rare (fraud ~1%) → Class weights or threshold moving (SMOTE with care); evaluate with PR-AUC, precision@k

Images, text, sequences at scale → Deep learning (awareness) — usually not better than GBM on tabular data fallback: Use GBM

What does the series look like?
