# Confidence scorecard

Rate yourself 1–5 on each competency **before the course** and **after each day**. Link each rating to evidence — an exercise
passed, an anomaly found, a recipe reused. The bars compare your **latest self-rating** (blue) with **demonstrated skill**
(green), computed from your best quiz scores in the related lessons and the anomalies you found. Confidence should be earned.

| Rating | Meaning |
| --- | --- |
| 1 | I recognise the term |
| 2 | I can explain it with help |
| 3 | I can apply it with Claude Code and check the output |
| 4 | I can choose it over alternatives and defend the choice |
| 5 | I can review someone else's use of it and coach them |
