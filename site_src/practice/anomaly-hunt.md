# Anomaly Hunt

The datasets contain **42 planted issues** — data errors, traps and genuine phenomena. Each card gives you a clue and asks for
one number your analysis should produce. Submit it; if it is within the expected range, the card unlocks and names the issue.

Work through Claude Code: ask it to investigate, then **verify** the number yourself. Hints point to the right Navigator node.
Progress is saved in this browser (export it from [My progress](progress.md)).

!!! warning "Honour code"
    The checker runs in your browser, so the expected ranges are technically visible in the page source. Looking defeats the purpose.
