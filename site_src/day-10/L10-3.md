# L10.3 · Navigator consolidation: scenario sprint

<p class="lesson-meta">Day 10 · Parts A + B · Basic → Advanced 60 min · Leader 45 min · Prerequisites: Navigator trees used on Days 1–9 · Recipes: none</p>

{{ here("N-DESC-PROFILE") }}

**Objectives** — you can: go from a plain-English business question to the right Navigator node in under a minute; name the
assumption check and the fallback; and coach a junior through the map instead of giving them the answer.

## 1. How the sprint works

=== "Basic → Advanced"

    Twenty business questions, one minute each. For each: (1) the data type and question type; (2) the Navigator node; (3) the
    assumption check; (4) the fallback if the check fails. Use the [interactive map](../navigator/index.md) and the
    [scenario atlas](../navigator/scenarios.md). Score yourself with the quiz below, then redo the ones you missed from the map.

=== "Leader"

    Coach, don't tell. For each question a Basic → Advanced colleague brings you, ask in order: *What decision? What's the outcome and its
    type? Is it a comparison, a relationship, a prediction, a forecast, a cause or a check? What would make the answer wrong?* Then
    let them find the node.

## 2. The ten tree roots (memorise these)

| Question type | Start at |
| --- | --- |
| What does the data look like / is it right? | `N-DESC-PROFILE`, `N-DESC-QUALITY` |
| Which distribution? | `N-DIST-*` |
| Are groups different? | `N-TEST-*` |
| Design an experiment | `N-EXP-POWER`, `N-EXP-SRM` |
| How does Y depend on X? | `N-REG-*` |
| Predict / classify | `N-ML-*`, `N-METRIC-*` |
| Group similar items | `N-CLUST-*`, `N-SEG-*` |
| Find the unusual | `N-ANOM-*` |
| Forecast | `N-FCST-*` |
| Did X cause Y? | `N-CAUSAL-*` |
| Is the model still OK? | `N-MON-*` |

## 3. Sprint warm-up (worked)

| Question | Node | Check | Fallback |
| --- | --- | --- | --- |
| "Is average basket higher in Hyper stores than Super?" | `N-TEST-2G-MEAN` | skew, outliers, unequal variance | Welch on log, or permutation |
| "Do complaints vary by branch more than chance?" | `N-TEST-COUNT` | over-dispersion | NB GLM |
| "Which customers will default?" | `N-ML-GBM` vs `N-REG-LOGIT` | leakage, time split | scorecard for explainability |
| "Did the loyalty programme raise spend?" | `N-CAUSAL-DID` | pre-trends; selection | randomised offer |
| "Is the score still working?" | `N-MON-PSI`, `N-MON-CONCEPT` | mix change | recalibrate / rebuild |

## 5. Scenario matrix

=== "Basic → Advanced"

    | Signal word in the question | Usually |
    | --- | --- |
    | "different", "higher", "compare" | `N-TEST-*` |
    | "drives", "depends", "effect of" (observational) | `N-REG-*` then `N-CAUSAL-DAG` |
    | "caused", "because of", "did it work" | `N-CAUSAL-*` or an experiment |
    | "predict", "score", "who will" | `N-ML-*` |
    | "next month", "how many will" | `N-FCST-*` |
    | "unusual", "suspicious" | `N-ANOM-*` |

=== "Leader"

    | Junior says | You ask |
    | --- | --- |
    | "I ran a t-test" | "On what data type, and did you check skew?" |
    | "The model is 99% accurate" | "What's the base rate and is there leakage?" |
    | "Sales rose after the change" | "Compared with what?" |

## 6. Traps

!!! warning "Traps"
    Choosing the method you know rather than the one the question needs; skipping the assumption check; treating a relationship
    question as a causal one.
