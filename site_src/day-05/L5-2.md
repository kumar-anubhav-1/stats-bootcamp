## 2. Concept

=== "Basic → Advanced"

    ### 2.1 What the assumptions are — and which matter most

    | Assumption | Consequence if violated | Check | Fix |
    | --- | --- | --- | --- |
    | Independent errors | SEs far too small | design / Durbin-Watson for time | cluster-robust SEs, model the dependence |
    | Correct functional form | biased coefficients | residuals vs fitted, vs each x | transform, splines (L5.6) |
    | Constant variance | wrong SEs (coefficients fine) | Breusch-Pagan, fan-shaped residuals | log outcome, HC3 robust SEs |
    | Normal errors | matters little with large n | Q-Q plot | robust methods for small n |
    | No perfect collinearity | unstable coefficients | VIF | combine, drop, regularise |

    ### 2.2 Heteroscedasticity: raw vs log units

    | Model (Beverages store-weeks) | Breusch-Pagan p | Residual skew |
    | --- | --- | --- |
    | raw units | {{ a.d5_bp_raw_p }} | {{ a.d5_raw_resid_skew }} |
    | log units | {{ a.d5_bp_log_p }} | {{ a.d5_log_resid_skew }} |

    Big stores vary more in absolute units — the residual plot is a fan. Logging the outcome removes most of it (residuals
    become symmetric) though with 4,000 rows the test still detects some. Use **HC3 robust SEs** as a default: for raw units the
    temperature SE moves from {{ a.d5_raw_temp_se }} to {{ a.d5_raw_temp_se_hc3 }}. The recipe applies HC3 automatically for OLS.

    ### 2.3 Multicollinearity: income and limit (F06)

    Credit limits are set at ~25% of income (L5.1), so for cards income and limit correlate at **r = {{ a.d5_il_corr_cards }}**.
    VIF (how much a coefficient's variance is inflated by correlation with the other predictors):

    | Predictor | VIF |
    | --- | --- |
    {% for k, v in a.d5_vif.items() %}| {{ k }} | {{ v }} |
    {% endfor %}

    VIF > 5 (some use 10) is a warning. Five logistic fits on random 3,000-account samples:

    | Sample | β income (per 10k) | β limit (per 10k) |
    | --- | --- | --- |
    {% for s in a.d5_flip %}| {{ loop.index }} | {{ s.inc }} | {{ s.lim }} |
    {% endfor %}

    Income's sign flips in {{ a.d5_flip_n_inc_pos }} of 5 samples. The model can estimate the **combined** effect but cannot split
    it. Fixes: keep one (income alone: β = {{ a.d5_inc_only_b }}, SE {{ a.d5_inc_only_se }} — stable), combine (limit ÷ income is
    nearly constant here, so it adds nothing), or regularise (L5.4). Predictions are unaffected; interpretation is.

    ### 2.4 Influence

    **Leverage** = unusual x-values; **Cook's distance** = how much the fitted model would change without the row. In the Beverages
    model the largest Cook's D is {{ a.d5_cook_max }} and {{ a.d5_cook_n_4n }} rows exceed the 4/n rule of thumb — expected with 4,160
    rows. **Inspect** flagged rows (data errors? holiday weeks? the S017 level shift, R08?) — never delete them automatically.

    ### 2.5 Autocorrelation

    Weekly sales from the same store are correlated over time. Durbin-Watson ≈ 2 means no first-order autocorrelation; values near 0
    mean strong positive autocorrelation and over-optimistic SEs. Fixes: cluster SEs by store, add lags, or time-series models (Day 7).

=== "Leader"

    !!! abstract "Refresh"
        Diagnostics decide whether a model's SEs and coefficients can be trusted. Independence and functional form matter most;
        normality least. Collinearity breaks interpretation, not prediction.

    **Judgement points**

    - **Flipping signs are a symptom, not a finding.** Income "raising" risk in one version is collinearity with limit — ask for VIF
      before anyone builds a story on it.
    - **Adverse-action reasons need stable coefficients.** A credit model whose reasons flip between refits fails explainability
      requirements (L6.7).
    - **Robust SEs are cheap insurance.** Make HC3 (or cluster-robust) the team default for business regressions.

    !!! tip "Coaching card"
        Ask for three things with every regression: the residual plot, VIFs, and the five most influential rows with an explanation.

## 5. Output anatomy — diagnostics section

| Line | Read as |
| --- | --- |
| Breusch-Pagan p | small → unequal variance; SEs need HC3 (recipe default) |
| Residual skew | > 1 in absolute value → consider a transform |
| Cook's distance | inspect rows above 4/n; explain before acting |
| VIF | > 5 → coefficients of those terms are not individually interpretable |
| `diagnostics.png` | fan shape, curvature, heavy tails |

## 6. Scenario matrix

=== "Basic → Advanced"

    | Symptom | Diagnosis | Action |
    | --- | --- | --- |
    | fan-shaped residuals | heteroscedasticity | log outcome; HC3 |
    | curved residual pattern | wrong functional form | transform x; splines |
    | VIF > 5, flipping signs | collinearity | drop/combine/regularise |
    | a few huge Cook's D | influential rows | investigate; robust regression |
    | residuals correlated over time | autocorrelation | cluster SEs; time-series model |

=== "Leader"

    | Report says | You ask | Norm |
    | --- | --- | --- |
    | "income increases default risk" | VIF with limit? | VIF < 5 for interpreted terms |
    | "we removed outliers to improve R²" | which, why? | document every exclusion |
    | "p < 0.001 on weekly data" | clustered/autocorrelated SEs? | independence first |
