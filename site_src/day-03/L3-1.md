## 2. Concept

=== "Basic → Advanced"

    ### 2.1 Estimates, estimators and their errors

    A **parameter** is the true value in the population (the average basket of every shopper who could visit); a **statistic** is what
    we compute from the data we have. A good estimator is **unbiased** (right on average), **consistent** (closer as n grows) and
    **efficient** (small spread). The sample mean is all three for most business data — but it is not *robust*: one bulk buyer moves it.

    **Maximum likelihood (intuition).** Pick the parameter value that makes the observed data most probable. The sample proportion
    is the maximum-likelihood estimate of a rate; the lognormal fits of L2.3 were maximum-likelihood fits.

    ### 2.2 The confidence interval

    $$\text{estimate} \pm \text{critical value} \times \text{standard error}$$

    Mean basket value from {{ a.d3_n_baskets | n }} baskets: **{{ a.d3_basket_mean }}** (SD {{ a.d3_basket_sd }}, SE
    {{ a.d3_basket_se }}). 95% CI: **{{ a.d3_basket_ci[0] }} – {{ a.d3_basket_ci[1] }}**.

    | Level | Interval | Width |
    | --- | --- | --- |
    | 90% | {{ a.d3_basket_ci90[0] }} – {{ a.d3_basket_ci90[1] }} | narrower: less confidence |
    | 95% | {{ a.d3_basket_ci[0] }} – {{ a.d3_basket_ci[1] }} | the default |
    | 99% | {{ a.d3_basket_ci99[0] }} – {{ a.d3_basket_ci99[1] }} | wider: more confidence |

    **What 95% means.** If we repeated the sampling many times and built an interval each time, about 95% of those intervals would
    contain the true mean. It is a property of the *method*. It does **not** mean "95% of baskets lie in this range" (individual
    baskets range from under 5 to over 1,000) and, strictly, it does not mean "95% probability the true value is in *this* interval"
    (that is a Bayesian credible interval — L4.3).

    ### 2.3 Width and sample size

    The SE shrinks with √n, so **four times the data halves the width**. Expected 95% CI width for mean basket value:

    | n | Width |

    | 400 | {{ a.d3_ci_width_by_n[400] }} |

    ### 2.4 When the textbook interval lies: heavy tails

    We drew thousands of samples from our baskets and checked how often the t-interval caught the true mean:

    | n per sample | Actual coverage of a "95%" t-interval |
    | --- | --- |
    | 30 | **{{ a.d3_t_coverage[30] }}%** |
    | 200 | **{{ a.d3_t_coverage[200] }}%** |

    Bulk buyers (R07) make the distribution so skewed that most samples miss the big baskets — their interval is too narrow and sits
    too low — while the few samples that catch one get a very wide interval. Remedies: a **bootstrap** interval (L3.2), a log-scale analysis, or report the **median** with its CI.

    ### 2.5 Intervals for proportions — Wald vs Wilson

    The textbook **Wald** interval p̂ ± 1.96·√(p̂(1 − p̂)/n) breaks for rare events. At the fraud base rate
    ({{ a.d3_fraud_p }}%) with n = 300, a simulated "95%" Wald interval covered the truth only **{{ a.d3_wald_cov }}%** of the time —
    in {{ a.d3_zero_share }}% of samples there were zero frauds and Wald returned "0 to 0". The **Wilson** interval covered
    **{{ a.d3_wilson_cov }}%**. Use Wilson (or exact Clopper-Pearson) for rates.

    | Segment | Defaults / n | Rate | 95% Wilson CI |
    | --- | --- | --- | --- |
    | All accounts | {{ (a.d3_def_rate * a.fi_rows / 100) | round(0) | int | n }} / {{ a.fi_rows | n }} | {{ a.d3_def_rate }}% | {{ a.d3_def_ci[0] }} – {{ a.d3_def_ci[1] }}% |
    | Students | {{ a.d3_stu_def }} / {{ a.d3_stu_n | n }} | {{ a.d3_stu_rate }}% | {{ a.d3_stu_ci[0] }} – {{ a.d3_stu_ci[1] }}% |
    | Branch {{ a.d3_small_branch }} | {{ a.d3_small_branch_def }} / {{ a.d3_small_branch_n }} | {{ a.d3_small_branch_rate }}% | {{ a.d3_small_branch_ci[0] }} – {{ a.d3_small_branch_ci[1] }}% |

    The student interval lies entirely above the overall rate; the small branch's interval is almost four times wider than its rate
    would suggest — a branch league table without intervals would rank it "best" on eight defaults.

    ### 2.6 Interval for a difference

    The two-group CIs of L3.4 follow the same recipe: difference ± critical value × SE of the difference. Always report the
    difference **with** its interval (e.g. unverified income defaults {{ a.l34_ver_rd_pp }} pp more, 95% CI {{ a.l34_ver_ci_pp[0] }}
    – {{ a.l34_ver_ci_pp[1] }} pp).

=== "Leader"

    !!! abstract "Refresh"
        A CI is the range of values compatible with the data at a chosen confidence level. Width ∝ 1/√n. Heavy tails and rare events
        break textbook intervals; bootstrap or Wilson fix them. "95%" describes the method, not individual values.

    **Judgement points**

    - **Every KPI needs its interval.** A branch default rate of {{ a.d3_small_branch_rate }}% on {{ a.d3_small_branch_n }} accounts
      is compatible with anything from {{ a.d3_small_branch_ci[0] }}% to {{ a.d3_small_branch_ci[1] }}% — not evidence of better
      underwriting.
    - **Ask what the interval was computed on.** Lines inside baskets, months inside accounts and weeks inside stores are not
      independent; intervals computed on them are too narrow (L3.2).
    - **Precision is purchasable.** Halving an interval costs four times the data — decide what precision the decision needs first.

    !!! tip "Coaching card"
        When a junior reports "the average basket is 50.52", ask: *"Give me the interval, the n, and whether bulk buyers are in it."*

## 5. Output anatomy — an interval in a report

| Element | Example | Why it matters |
| --- | --- | --- |
| Estimate | {{ a.d3_basket_mean }} | the best single guess |
| Interval and level | {{ a.d3_basket_ci[0] }} – {{ a.d3_basket_ci[1] }} (95%) | the range compatible with the data |
| n and unit | {{ a.d3_n_baskets | n }} baskets | determines width; must be the independent unit |
| Method | t-interval / Wilson / bootstrap | wrong method → wrong coverage |
| Caveat | heavy tail; bulk buyers included | tells the reader when to distrust it |

## 6. Scenario matrix

=== "Basic → Advanced"

    | Situation | Interval |
    | --- | --- |
    | mean of a roughly symmetric variable | t-interval |
    | mean of a heavy-tailed variable | bootstrap (BCa) or log scale; report median too |
    | proportion, n·p ≥ 10 | Wilson (Wald acceptable) |
    | rare proportion or small n | Wilson or Clopper-Pearson |
    | difference of two means / rates | Welch CI / Newcombe or Wald difference |
    | median, ratio, percentile | bootstrap |

=== "Leader"

    | Report says | You ask | Norm |
    | --- | --- | --- |
    | a ranking of branches by rate | intervals and n for each | small units always land at the extremes |
    | "average up 3%" | CI of the change | a CI crossing 0 is not a change |
    | "95% of customers spend 48–53" | that's the mean's CI, not customers | CIs describe estimates |
