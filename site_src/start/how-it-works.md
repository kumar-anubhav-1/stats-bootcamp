# How this course works

## The rhythm of a day (Days 1–9, about 8 hours)

| Time | Basic → Advanced path | Leader path |
| --- | --- | --- |
| 09:00–09:30 | **Joint:** Navigator walkthrough — where today sits on the map | Joint |
| 09:30–12:30 | Concept + lab blocks (3 lessons) | 15-minute refresh per lesson, then output-anatomy and decision drills |
| 13:15–16:15 | Concept + lab blocks (3–4 lessons) | Scenario matrices, coaching cards, review of Basic → Advanced outputs |
| 16:15–16:45 | **Joint junior–leader review huddle** using the approval checklist | Joint |
| 16:45–17:30 | Mastery gate (quiz + data task) | Mastery gate (scenario quiz + "read and decide" task) |
| 19:00–20:30 | Evening lab (Days 2, 3, 5, 6, 8, 9): extra exercises + Anomaly Hunt | Optional decision cases |

## You will not write code

You work in **VS Code with Claude Code** and instruct it in plain English. What you learn is *what to ask for*, *what to check*,
and *how to judge the answer*. Every lesson gives you **prompt cards** (weak → better → expert) and a list of things to verify in
what Claude Code returns. Day 0 teaches the playbook.

## Proof that you have learned it

- **Mastery gates** at the end of each day (pass mark 75%). Missed topics point to remedial practice before you move on.
- **Anomaly Hunt**: find, explain and fix the 42 planted issues.
- **Confidence scorecard**: your self-rating next to demonstrated evidence, so confidence is earned.
- **Day 10**: a transfer test on an unseen dataset, a capstone business readout, and a held-out final exam on data generated
  from a different seed (answers cannot be memorised). Leaders also take a code-review exam.
