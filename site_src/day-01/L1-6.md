**Objectives** — you can: tell errors, genuine extremes and signals apart; flag outliers with Tukey fences, z-scores and robust
(MAD) z-scores and explain why they disagree; choose and report a treatment; apply log/Box-Cox transforms, scaling, binning and
encoding — and avoid target-encoding leakage.

=== "Retail"

## 2. Concept

=== "Basic → Advanced"

    ### 2.1 Three kinds of "outlier"

    | Kind | Example | Treatment |
    | --- | --- | --- |
    | **Error** | unit price 100× list (R02) | correct or quarantine |
    | **Genuine extreme** | bulk buyer's basket (R07) | keep; often model as its own segment |
    | **Signal** | returns-abuse cluster (R17), fraud | investigate — this is what you are looking for |

    ### 2.2 Detection rules

    | Rule | Definition | Clean baskets flagged (of {{ a.d1_b_n | n }}) |
    | --- | --- | --- |
    | Tukey fence, k = 1.5 | above Q3 + 1.5 × IQR = {{ a.d1_tukey_upper }} | {{ a.d1_n_tukey }} |
    | Tukey fence, k = 3 | above Q3 + 3 × IQR = {{ a.d1_tukey_far_upper }} | {{ a.d1_n_tukey_far }} |
    | Plain z-score > 3 | (x − mean) ÷ SD | {{ a.d1_n_z3 }} |
    | Robust z-score > 3.5 | 0.6745 × (x − median) ÷ MAD | {{ a.d1_n_mz35 }} |

    **Why they disagree.** On skewed data, k = 1.5 flags many ordinary large baskets. The plain z-score uses the mean and SD — both
    inflated by the very values you are hunting — so it under-flags (**masking**). On the *raw* data, the 25 decimal-shift lines sit in
    {{ a.d1_err_baskets }} baskets; plain z > 3 catches only **{{ a.d1_err_caught_z3 }}**, the robust score catches
    **{{ a.d1_err_caught_mz }}**. The errors raise the SD from {{ a.d1_sd_clean }} to {{ a.d1_sd_raw }}.

    ### 2.3 Treatments — and what they do to the answer

    | Treatment | Mean basket |
    | --- | --- |
    | keep all | {{ a.d1_b_mean }} |
    | cap at P99 | {{ a.d1_mean_capped99 }} |
    | exclude robust outliers | {{ a.d1_mean_excl_outliers }} |
    | 10% trimmed mean | {{ a.d1_b_trim10 }} |
    | median (no treatment needed) | {{ a.d1_b_median }} |

    About **{{ a.d1_flagged_bulk_share_pct }}%** of robust-flagged baskets come from 25 bulk-buying customers: one identifiable segment.

    ### 2.4 Transformations

    | Transform | What it does | Example |
    | --- | --- | --- |
    | **Log** | compresses the right tail; multiplicative → additive | income skew {{ a.d1_inc_skew }} → {{ a.d1_loginc_skew }} |
    | **Box-Cox** (positive) / **Yeo-Johnson** (any sign) | finds the power that best normalises | λ = {{ a.d1_boxcox_lambda }} ≈ 0 → it is essentially a log |
    | **Standardise** (z) / **min-max** | puts variables on comparable scales | needed for K-means, KNN, regularisation |
    | **Binning** | numeric → categories | scorecard bins (Day 8); loses detail |

    ### 2.5 Encoding categorical variables

    | Encoding | Use | Risk |
    | --- | --- | --- |
    | One-hot | few categories | many columns |
    | Ordinal | ordered categories (age band) | implies equal spacing |
    | **Target encoding** | many categories (branch, postcode) | **leakage** if computed on the same rows it is used for |

    A random 2,000-level code with no information about default reaches an AUC of **{{ a.d1_te_auc_leaky }}** when target-encoded on all
    rows — and **{{ a.d1_te_auc_oof }}** (chance) when encoded out-of-fold. Fit encoders inside cross-validation.

=== "Leader"

    !!! abstract "Refresh"
        Error / genuine extreme / signal. Robust z (median, MAD) for skewed data; plain z masks. Treatment is a decision that moves the
        result — report it. Log for skewed positive amounts. Target encoding leaks unless done out-of-fold.

    **Judgement points**

    - **Standardise the treatment, not the threshold.** Agree team-wide: errors quarantined; genuine extremes kept and reported;
      segments like bulk buyers modelled separately. Then the number stops changing with the analyst.
    - **Never delete signals.** Fraud and abuse look like outliers. An analyst who "cleans" them away removes the business problem.
    - **Interpretability matters.** λ ≈ 0 → use log (coefficients become % effects); an exotic λ buys little and costs explanation.
    - **Leakage hides in feature engineering.** Ask how every encoded or aggregated feature was fitted.

    !!! tip "Coaching card"
        Ask: *"Show me the result with and without the treatment."* If the conclusion flips, the treatment is the finding — and it
        must be in the headline, not the appendix.

## 3. Assumptions and fallbacks

| Situation | Use | Fallback |
| --- | --- | --- |
| Skewed, one variable | robust z / percentiles | log scale then z |
| Many variables | Isolation Forest / LOF (Day 8) | Mahalanobis on robust covariance |
| Unsure error vs genuine | keep + flag + sensitivity | ask the data owner |
| Model needs symmetric inputs | log / Box-Cox | rank / quantile transform |

## 5. Output anatomy — `rcp_outliers`

| Line | Meaning | Read as |
| --- | --- | --- |
| IQR, Q1, Q3 | robust spread | fences are built from these |
| MAD | robust SD substitute (× 1.4826 ≈ SD for normal data) | basis of the robust z |
| counts per rule | sensitivity of each rule | big differences = skewed data |
| treatment table | how each choice moves mean and SD | the size of the "analyst effect" |

## 6. Scenario matrix

=== "Basic → Advanced"

    | Pattern | Meaning | Next |
    | --- | --- | --- |
    | z-score flags few, robust z flags many | masking by inflated SD | trust the robust rule |
    | Flagged units share an attribute | a segment, not noise | analyse the segment |
    | Removing outliers flips a conclusion | fragile result | report both |

=== "Leader"

    | Pattern | Likely causes | Action — why / when / when not | Norm |
    | --- | --- | --- | --- |
    | Extremes concentrated in a few customers | bulk/business buyers | **Separate segment** in pricing and CRM; not deletion | Document segment rules |
    | Extremes concentrated in a store / time | errors or abuse | **Investigate** (audit, fraud team) | — |
    | Feature suspiciously predictive after encoding | target leakage | **Reject** until fitted out-of-fold | All encoders inside CV |
