## 2. Concept

=== "Basic → Advanced"

    ### 2.1 Vocabulary

    **Population** (all accounts) → **sample** (the ones you analyse) → **statistic** (sample default rate) estimating a
    **parameter** (true default rate, {{ a.d2_true_default_pct }}%). Sampling error is random; **bias** is systematic and does not shrink
    with more data.

    ### 2.2 Sampling designs

    | Design | How | When |
    | --- | --- | --- |
    | Simple random | every unit equally likely | default |
    | Stratified | sample within groups, combine with weights | guarantee subgroup sizes; gain precision when groups differ a lot |
    | Cluster | sample whole groups (stores, branches) | cheaper fieldwork; less precise |
    | Systematic | every k-th unit | easy; dangerous if the list has a cycle |

    In 2,000 simulated samples of 500 accounts, the SE of the default rate was {{ a.d2_srs_se_pp }} pp (simple random) vs
    {{ a.d2_strat_se_pp }} pp (stratified by channel) — almost no gain, because default varies mostly *within* channels. Stratify to
    control subgroup sizes, not as a guaranteed precision boost.

    ### 2.3 Biases

    | Bias | Course example | Effect |
    | --- | --- | --- |
    | **Convenience** | branch accounts only: {{ a.d2_branch_only_pct }}% default vs {{ a.d2_true_default_pct }}% | risk understated |
    | **Selection** | model on booked accounts only (declined scored {{ a.d2_declined_score }} vs booked {{ a.d2_booked_score }}) | no evidence below the cut-off |
    | **Survivorship** | Snacks growth on current SKUs {{ a.d2_surv_current_pct }}% vs true {{ a.d2_surv_true_pct }}% | growth invented |
    | **Self-selection** | loyalty members' baskets {{ a.d2_loyal_naive_pct }}% bigger — but big spenders join | effect overstated |
    | **Non-response** | household size missing for large households (L1.3) | profiles skewed |

    ### 2.4 Simpson's paradox

    Units per line: promo lines are **{{ a.d2_simpson_overall_pct }}%** vs non-promo overall — yet within every format promo lines sell
    more ({{ a.d2_simpson_within | kv("%") }}). Why: promotions are concentrated in Express stores ({{ a.d2_simpson_promo_share | kv("%") }}
    of lines on promo), where baskets are small. The format mix, not the promotion, drives the pooled result.

    ### 2.5 Confounding

    A **confounder** affects both the "treatment" and the outcome. Displays run on {{ a.d2_disp_promo_pct }}% of promo lines vs
    {{ a.d2_disp_nonpromo_pct }}% of others — any "promotion effect" includes the display effect. Spend propensity drives both loyalty
    membership and basket size. Name confounders before trusting any observational comparison.

=== "Leader"

    !!! abstract "Refresh"
        Bias does not shrink with n. Ask how the sample was drawn and who is missing. Simpson's paradox: a mix variable reverses the pooled
        comparison. Confounders explain associations without causation.

    **Judgement points**

    - **"Where did the sample come from?"** is the first question for any estimate. Convenience samples (one branch, one region, recent
      customers) systematically mislead.
    - **Survivorship is built into most master data.** Current product lists, active customers and booked accounts all hide what failed.
    - **Below-cut-off risk is unknowable from booked data.** Learn it with a small, controlled approval test, not by extrapolation.
    - **Stratify every executive comparison** by the obvious mix variables (format, channel, vintage) before it goes on a slide.

    !!! tip "Coaching card"
        For any comparison, ask the junior: *"Name two things that differ between these groups besides the thing you're comparing."* Then make
        them show the comparison within those groups.

## 6. Scenario matrix

=== "Basic → Advanced"

    | Pattern | Meaning | Next |
    | --- | --- | --- |
    | Pooled and stratified disagree | Simpson / confounding | report stratified |
    | Sample drawn from an easy source | convenience bias | redefine the sampling frame |
    | Only "survivors" in the data | survivorship | recover archived records |
    | Group chose itself | self-selection | causal methods (Day 9) |

=== "Leader"

    | Pattern | Action — why / when / when not | Norm |
    | --- | --- | --- |
    | KPI comparison across formats/channels | **Require stratified view**; pooled only with a mix note | Mix-adjusted reporting |
