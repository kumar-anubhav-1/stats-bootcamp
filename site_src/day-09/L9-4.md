## 2. Concept

=== "Basic → Advanced"

    ### 2.1 Frequency (F17)

    Claim frequency is **{{ a.d9_ins_freq }}** claims per policy-year. Counts are over-dispersed (variance/mean
    {{ a.d9_ins_dispersion }}); with an exposure offset, negative binomial (α = {{ a.d9_ins_nb_alpha }}) beats Poisson: AIC
    {{ a.d9_ins_aic_nb }} vs {{ a.d9_ins_aic_pois }}.

    ### 2.2 Severity

    Mean claim **{{ a.d9_ins_mean_sev | n }}** vs median {{ a.d9_ins_median_sev | n }} — right-skewed (Gamma/lognormal). Three
    catastrophic claims are **{{ a.d9_ins_top3_share }}%** of all losses. Loss ratio {{ a.d9_ins_loss_ratio }} overall vs
    {{ a.d9_ins_loss_ratio_excat }} excluding them: price attritional losses with a GLM and add a **large-loss loading**
    (here ≈ {{ a.d9_ins_cat_loading_pct }}% on attritional losses), or buy reinsurance.

    ### 2.3 Aggregate loss, VaR and ES

    Simulate 20,000 years: number of claims from the NB, severities resampled from actual claims (including the tail).

    | Measure (millions, one portfolio-year) | Value |
    | --- | --- |
    | Premium | {{ a.d9_ins_premium }} |
    | Expected loss | {{ a.d9_ins_el }} |
    | VaR 99.5% (1-in-200 year) | {{ a.d9_ins_var995 }} |
    | Expected shortfall 99.5% (average beyond VaR) | {{ a.d9_ins_es995 }} |
    | Capital = VaR − expected loss | {{ a.d9_ins_capital }} |

    **VaR** answers "how bad at the 99.5th percentile"; **ES** answers "how bad on average when it's worse than that" — ES is never
    below VaR and sees the tail VaR ignores.

    {{ chart("var", "Drag the confidence level: VaR (red) is the threshold; expected shortfall (purple) is the average beyond it.") }}

    ### 2.4 Credit portfolio (one-factor Vasicek)

    Exposure {{ a.d9_cr_ead }}M, PD {{ a.d9_cr_pd }}%, LGD 60%, asset correlation 0.15. Defaults cluster when the economy (a common
    factor) is bad:

    | Millions | Base | Stress: PD × 2.5 (2025Q2 vintage behaviour) |
    | --- | --- | --- |
    | Expected loss | {{ a.d9_cr_el }} | {{ a.d9_cr_stress_el }} |
    | VaR 99.9% | {{ a.d9_cr_var999 }} | {{ a.d9_cr_stress_var999 }} |
    | ES 99.9% | {{ a.d9_cr_es999 }} | — |

    Capital (VaR − EL) is **{{ a.d9_cr_capital }}M** — about {{ (a.d9_cr_capital / a.d9_cr_el) | round(1) }}× expected loss, because
    correlation fattens the tail.

=== "Leader"

    !!! abstract "Refresh"
        Expected loss is priced; unexpected loss is held as capital. Tails, not averages, sink portfolios.

    **Judgement points**

    - **Pricing:** the book runs at a loss ratio of {{ a.d9_ins_loss_ratio }} — premiums don't cover expected claims once catastrophes
      are included. Reprice, reinsure, or both.
    - **Risk appetite** is a statement like "we hold capital to survive a 1-in-200 year" — choose the percentile, then the measure (ES
      for tail sensitivity).
    - **Stress tests** ask "what if" (PD × 2.5) rather than "how likely" — essential when history lacks the scenario.

    !!! tip "Coaching card"
        Ask: *"What's the 1-in-200 loss, what's the average beyond it, and which assumption moves them most?"*

## 6. Scenario matrix

=== "Basic → Advanced"

    | Question | Tool |
    | --- | --- |
    | claim counts with exposure | Poisson/NB GLM with offset |
    | claim sizes | Gamma/lognormal GLM; cap + loading |
    | aggregate loss | Monte Carlo (frequency × severity) |
    | correlated credit losses | one-factor model / simulation |
    | rare scenarios | stress tests |

=== "Leader"

    | Metric | Use |
    | --- | --- |
    | loss ratio | pricing adequacy |
    | VaR | capital at a percentile |
    | ES | tail severity; preferred by regulators for market risk |
