## 2. Concept

=== "Basic → Advanced"

    ### 2.1 The pyramid

    1. **Answer** (one sentence, with the decision).
    2. **Three supporting points**, each with a number and its uncertainty.
    3. **Evidence** (charts, tables) in an appendix or on request.

    ### 2.2 Worked example — promotion review (retail)

    > **Recommendation: keep the Hair Care mechanic, cut deep Snacks discounts.** (1) The Hair Care test lifted units by
    > {{ a.d9_r09_twfe_pct }}% (95% CI {{ a.d9_r09_twfe_ci[0] }}–{{ a.d9_r09_twfe_ci[1] }}%) versus control stores. (2) Snacks
    > promotions double volume (+{{ a.d8_promo_uplift_pct }}%) but return only {{ a.d8_promo_roi }} of their discount cost in margin,
    > and ~{{ a.d8_cannibal_share }}% of the gain is cannibalised. (3) Loyalty members' higher spend is mostly selection — the causal
    > programme effect is about +{{ a.d9_r20_twfe }}%, so don't credit promotions targeted at members with the +{{ a.d9_r20_naive }}% gap.

    ### 2.3 Worked example — default readout (finance)

    > **Defaults rose because we booked a riskier mix through the partner channel, and our score under-predicts it; we will tighten
    > partner cut-offs and recalibrate.** (1) 2025Q2–Q3 vintages default at {{ a.d9_f12_def_late }}% vs {{ a.d9_f12_def_early }}%
    > earlier; the partner channel is {{ a.d9_f11_mix.partner }}% of them (score PSI {{ a.d9_f11_psi }}). (2) The score still ranks
    > (AUC {{ a.d9_f12_auc_late }}) but predicts {{ a.d9_cal_pred_late }}% against {{ a.d9_cal_actual_late }}% actual. (3) The new
    > collections strategy raises cures by {{ a.d9_f16_diff }}pp (CI {{ a.d9_f16_ci[0] }}–{{ a.d9_f16_ci[1] }}), partly offsetting losses.

    ### 2.4 Charts

    One message per chart; title states the message ("Partner vintages default 3× faster"); annotate the decision point; avoid dual
    axes and 3-D; show uncertainty (intervals, ranges).

    ### 2.5 Drafting with Claude Code

    Ask for a draft from your verified numbers, then **edit**: check every number against the output files, remove hedges that hide
    the answer, add the decision and owner.

=== "Leader"

    !!! abstract "Refresh"
        Executives buy decisions, not analyses. Lead with the answer, quantify, show uncertainty, own the recommendation.

    **Stakeholder challenges to prepare for**

    | Challenge | Prepared answer |
    | --- | --- |
    | "Is it significant?" | effect size + CI + practical threshold (L3.5) |
    | "Isn't it just seasonality/mix?" | control group / DiD / mix decomposition (L5.7, L9.1) |
    | "Your model said otherwise last year" | monitoring evidence (L9.6) |
    | "What would change your mind?" | the test or data that would |

    !!! tip "Coaching card"
        Ask: *"What do you want me to decide, and how sure are you?"*

## 5. Output anatomy

| Section | Contents |
| --- | --- |
| headline | answer + decision |
| supports | 3 × (claim, number, uncertainty) |
| risks | what could make this wrong |
| next steps | actions, owners, dates |
| appendix | method, data, checks |

## 6. Scenario matrix

=== "Basic → Advanced"

    | Audience | Format |
    | --- | --- |
    | board | 1 slide, answer + 3 numbers |
    | functional head | 1 page + appendix |
    | analysts | notebook/report with methods |

=== "Leader"

    | Situation | Approach |
    | --- | --- |
    | bad news | lead with it, then the plan |
    | uncertain result | give the range and the test that resolves it |
    | contested finding | pre-wire key stakeholders |

## 7. Planted traps and reuse drill

!!! warning "Traps"
    Quoting naive numbers (R20 +38%, post-only R09); hiding the answer in the last slide; numbers without uncertainty.

**Reuse drill:** rewrite your Day 5 capstone readout in pyramid form.
