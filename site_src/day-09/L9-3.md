## 2. Concept

=== "Basic → Advanced"

    ### 2.1 What a neural network is

    Inputs → layers of weighted sums passed through non-linear **activations** (ReLU) → output (sigmoid for a probability). Training
    minimises a **loss** (log-loss) by gradient descent with an **optimiser** (Adam) over mini-batches. **Regularisation** — weight
    decay, dropout, early stopping — fights overfitting. Inputs must be **scaled**.

    On modest, tabular, mostly monotone data, the simple model wins; the MLP has {{ a.d9_dl_n_params }} parameters to fit and suffers
    most when data are small. This is typical: for tabular business data, **gradient boosting and well-built GLMs are the default**.

    ### 2.3 Where deep learning wins

    Unstructured data — images (shelf photos), text (complaints, reviews), audio (call centre), sequences at scale — where useful
    features are hard to hand-craft. **Embeddings** map items (words, products, customers) to vectors whose distances mean similarity.
    **Transformers** use attention to relate every token to every other and power LLMs.

    ### 2.4 LLMs in analytics

    - **RAG**: retrieve relevant documents (policy, complaint history) and give them to the LLM, so answers are grounded and citable.
    - **Uses:** classify and summarise complaints, draft narratives, code assistance (this bootcamp!).
    - **Risks:** hallucination, leakage of personal data, bias, prompt injection, non-reproducibility.

=== "Leader"

    !!! abstract "Refresh"
        Deep learning shines on images, text and audio. On tabular data, start with boosting or a GLM and demand a fair comparison.

    **Judgement points**

    - **Vendor claims:** ask for out-of-time results against *your* baseline (seasonal naive, GBM) on the same split (L7.3, L6.4).
    - **Explainability and regulation:** credit decisions need reasons; an MLP adds explanation burden for, here, no gain.
    - **LLM governance:** approved use cases, no personal data in public tools, human review of outputs, logging, evaluation sets.

    !!! tip "Coaching card"
        Ask: *"What did the simplest reasonable model score on the same test set?"*

## 6. Scenario matrix

=== "Basic → Advanced"

    | Data | First choice |
    | --- | --- |
    | tabular, < 1M rows | GBM / GLM |
    | images | convolutional nets / pretrained vision models |
    | text classification | pretrained Transformer embeddings + simple classifier |
    | long time series, many related | global models (GBM or deep) vs baselines |
    | Q&A over documents | RAG with citations |

    | "deep credit model" | gain vs regulatory burden |
