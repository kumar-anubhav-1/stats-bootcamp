## 2. Concept

=== "Basic → Advanced"

    ### 2.1 What a neural network is

    Inputs → layers of weighted sums passed through non-linear **activations** (ReLU) → output (sigmoid for a probability). Training
    minimises a **loss** (log-loss) by gradient descent with an **optimiser** (Adam) over mini-batches. **Regularisation** — weight
    decay, dropout, early stopping — fights overfitting. Inputs must be **scaled**.

    <div class="sb-chart" data-chart="activations" data-caption="The non-linear 'switches' inside a network. Click legend items to compare."></div>

    ### 2.2 An honest bake-off on our default data

    Same features, same 70/30 split:

    | Model | Parameters | Test AUC (17,500 training rows) | Test AUC (1,500 training rows) |
    | --- | --- | --- | --- |
    | Logistic regression | 11 | **0.831** | **0.824** |
    | Gradient boosting | many trees | 0.816 | — |
    | MLP (32, 16), weight decay | 897 | 0.791 | 0.743 |

    On modest, tabular, mostly monotone data, the simple model wins; the MLP has 897 parameters to fit and suffers
    most when data are small. This is typical: for tabular business data, **gradient boosting and well-built GLMs are the default**.

    ### 2.3 Where deep learning wins

    Unstructured data — images (shelf photos), text (complaints, reviews), audio (call centre), sequences at scale — where useful
    features are hard to hand-craft. **Embeddings** map items (words, products, customers) to vectors whose distances mean similarity.
    **Transformers** use attention to relate every token to every other and power LLMs.

    ### 2.4 LLMs in analytics

    - **RAG**: retrieve relevant documents (policy, complaint history) and give them to the LLM, so answers are grounded and citable.
    - **Uses:** classify and summarise complaints, draft narratives, code assistance (this bootcamp!).
    - **Risks:** hallucination, leakage of personal data, bias, prompt injection, non-reproducibility.

=== "Leader"

    !!! abstract "Refresh"
        Deep learning shines on images, text and audio. On tabular data, start with boosting or a GLM and demand a fair comparison.

    **Judgement points**

    - **Vendor claims:** ask for out-of-time results against *your* baseline (seasonal naive, GBM) on the same split (L7.3, L6.4).
    - **Explainability and regulation:** credit decisions need reasons; an MLP adds explanation burden for, here, no gain.
    - **LLM governance:** approved use cases, no personal data in public tools, human review of outputs, logging, evaluation sets.

    !!! tip "Coaching card"
        Ask: *"What did the simplest reasonable model score on the same test set?"*

## 6. Scenario matrix

=== "Basic → Advanced"

    | Data | First choice |
    | --- | --- |
    | tabular, < 1M rows | GBM / GLM |
    | images | convolutional nets / pretrained vision models |
    | text classification | pretrained Transformer embeddings + simple classifier |
    | long time series, many related | global models (GBM or deep) vs baselines |
    | Q&A over documents | RAG with citations |

## 8. Exercises

### Retail · NorthStar

??? example "R9-7 · Basic · Vendor neural forecast"
    **Business framing:** A vendor promises 30% better forecasts.

    **Deliverable:** Specify the backtest you'd require.

    ??? success "Expected finding and model answer"
        **Expected:** Rolling-origin, same horizon, vs seasonal naive and our model, MASE/WAPE by level (L7.3). *(tolerance: —)*

        **Model answer:** Fair comparison on your data.

        **Common wrong answer:** Accepting vendor in-sample metrics.

    **Leader drill:** What contract terms?

??? example "R9-8 · Applied · Shelf images"
    **Business framing:** Store ops wants on-shelf availability from photos.

    **Deliverable:** Explain why deep learning fits here and what data is needed.

    ??? success "Expected finding and model answer"
        **Expected:** Images → pretrained vision model fine-tuned on labelled photos; measure precision/recall of gaps. *(tolerance: —)*

        **Model answer:** Unstructured data is DL's home turf.

        **Common wrong answer:** Hand-crafting pixel features.

    **Leader drill:** Pilot scope and success metric?

??? example "R9-9 · Applied · Review summarisation"
    **Business framing:** Use an LLM to summarise product reviews.

    **Deliverable:** Governance checklist.

    ??? success "Expected finding and model answer"
        **Expected:** No personal data, evaluation sample, human review, cite source reviews (RAG), monitor drift. *(tolerance: —)*

        **Model answer:** Grounded, reviewed, logged.

        **Common wrong answer:** Publishing raw LLM summaries.

    **Leader drill:** Who signs off?

### Finance · Meridian

??? example "F9-7 · Basic · Bake-off"

    **Deliverable:** AUC: logistic, GBM, MLP; and with 1,500 rows.

        **Common wrong answer:** Trusting demo examples.

    **Leader drill:** Regulatory categories handled how?
