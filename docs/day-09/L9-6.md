## 2. Concept

=== "Basic → Advanced"

    ### 2.1 PSI

    PSI = Σ (actual% − expected%) × ln(actual% ÷ expected%) over bins of the reference distribution. Bands: < 0.10 stable,
    0.10–0.25 monitor, ≥ 0.25 act. Applied to each model input it's called CSI.

    ### 2.2 A logging change (R19)

    Online promotional lines: median `discount_pct` **23.2** before week 80 and **0.221**
    after — PSI **8.4**. A ×100 change is a unit change (20 → 0.2), first appearing in week
    80. After rescaling values ≤ 1, PSI is 0.076 — stable. Separately, the online share of
    baskets doubled (12.7% → 24.5%): real behaviour change, which **amplifies** the
    impact of the bug on any chain-level average. `rcp_drift` flags the ×100 automatically.

    ### 2.3 Population drift (F11)

    Application-score PSI by vintage vs 2023:

    | Vintage | PSI | Band |
    | --- | --- | --- |
    | 2023Q1 | 0.004 | stable |
    | 2023Q2 | 0.003 | stable |
    | 2023Q3 | 0.002 | stable |
    | 2023Q4 | 0.005 | stable |
    | 2024Q1 | 0.008 | stable |
    | 2024Q2 | 0.009 | stable |
    | 2024Q3 | 0.007 | stable |
    | 2024Q4 | 0.007 | stable |
    | 2025Q1 | 0.007 | stable |
    | 2025Q2 | 0.287 | act |
    | 2025Q3 | 0.26 | act |
    

    The jump in 2025Q2 coincides with the partner channel: partner 56.9% · branch 24% · online 19.1% of late applications.

    <div class="sb-chart" data-chart="psi" data-caption="Switch views: real population drift (scores) vs a logging bug (discount ×100)."></div>

    ### 2.4 Concept drift (F12)

    | | Early vintages | 2025Q2–Q3 |
    | --- | --- | --- |
    | AUC of application score | 0.826 | 0.775 |
    | Default rate | 2.6% | 9.92% |
    | Utilisation → default slope (log-odds, cards) | 1.13 | 1.97 |
    | Predicted default (early-trained model) | — | 4.97% vs actual 9.92% |

    Utilisation's CSI is only 0.105 (monitor), yet its relationship with default steepened and the model
    under-predicts by half. **Input monitoring alone misses concept drift**; track performance and calibration too.

    ### 2.5 Reject inference in monitoring (F18)

    17.3% of applicants are declined, scoring 68.3 points lower; we never see their outcomes.
    Performance measured on booked accounts flatters the model at low scores — even the booked bottom decile defaults at
    18.2%.

=== "Leader"

    !!! abstract "Refresh"
        Drift has three flavours: the pipeline changed (fix it), the population changed (recalibrate/re-weight), or the relationship
        changed (rebuild).

    **Decision ladder**

    | Signal | Action |
    | --- | --- |
    | PSI high, ×100 or new codes | data incident — fix pipeline, backfill |
    | PSI high, AUC stable, calibration off | recalibrate (intercept/slope) |
    | AUC falling, relationships changed | rebuild with recent data; review policy meanwhile |
    | new segment (partner channel) | separate model or segment-specific cut-off |

    !!! tip "Coaching card"
        Ask: *"Is this the data, the customers, or the world that changed?"*

## 6. Scenario matrix

=== "Basic → Advanced"

    | Symptom | Likely cause | Check |
    | --- | --- | --- |
    | median ×100 / ÷100 | unit change | pipeline release notes |
    | new category values | code change | mapping table |
    | PSI up, AUC stable | population drift | mix by channel/segment |
    | AUC down, CSI modest | concept drift | slopes by period |
    | defaults ≫ predicted | calibration drift | calibration-in-the-large |
