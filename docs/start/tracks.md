# Choose your path

Both paths use **the same datasets, the same labs and the same Navigator**. They differ in depth and emphasis.

| | Basic → Advanced | Leader |
| --- | --- | --- |
| Who | Anyone new to statistics and data science — students, career-changers, new analysts, curious professionals | Experienced professionals, managers and decision-makers who review analyses and act on them; concepts may be rusty |
| Concept depth | Micro-level, step by step, many worked examples | Refresh in minutes, then judgement |
| Emphasis | *How* to do it correctly | *Whether* it was done correctly and *what to decide* |
| Unique content | Graded labs, step-by-step builds | Output anatomy, scenario matrices with actions and norms, coaching cards, red flags, "read and decide" drills |
| Quizzes | 8+ per lesson: multiple choice, numbers from the data, spot the error | 5+ per lesson: interpret, decide, what would you ask the analyst |

**You can take the other path's quiz any time** — leaders to refresh basics, newcomers as stretch.

Take the [pre-bootcamp diagnostic](diagnostic.md): it recommends a path and flags the topics to revise.

## How to switch

Click the **Basic → Advanced** or **Leader** tab on any lesson. The choice is remembered across the whole site.

=== "Basic → Advanced"

    Basic → Advanced selected.

=== "Leader"

    Leader selected.

## Your route

- [Basic → Advanced route](route-basic.md) — every lesson, step by step, with labs.
- [Leader route](route-leader.md) — the same lessons, focused on reading results, deciding and coaching.

Both routes use the same lessons and data; the path only changes which layer you read and which drills you do.
