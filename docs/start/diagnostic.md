# Pre-bootcamp diagnostic

40 questions, about 35 minutes, across the whole syllabus. **It is not graded.** Answer honestly — skip rather than guess.

**How to read your result**

| Score | Recommendation |
| --- | --- |
| Below 45% | **Basic → Advanced path.** Do the Day 0 pre-work carefully. |
| 45–75% | **Basic → Advanced path**, attempt the Leader drills as stretch. |
| Above 75% *and* 10+ years' experience | **Leader path.** Use the topics you missed as your refresh list. |

Each question is tagged with its topic; note the tags of the ones you miss. The same blueprint is used for the post-bootcamp
test so your learning gain can be measured.
