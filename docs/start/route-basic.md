# Basic → Advanced route

<div class="path-chooser" markdown>
<button class="md-button md-button--primary" data-path="B">Set my path to Basic → Advanced</button>
</div>

For anyone new to the subject. Work through every lesson in order. In each lesson:

1. Read the **business question** — a real retail or banking problem you are about to solve.
2. Read the concept in the **Basic → Advanced** tab; play with the interactive charts.
3. Do the **learn-by-doing lab** with Claude Code (optional but strongly recommended).
4. Do the Basic and Applied exercises; try Stretch when you're comfortable.
5. Take the Basic → Advanced quiz — every option has an explanation, so wrong answers teach too.
6. End each day with the gate (75%).

**Total guided time on this path: about 87 hours** (plus exercises, gates and optional evening labs).

    Concept (Basic → Advanced tab) · prompt cards · learn-by-doing lab · Basic + Applied exercises · Basic → Advanced quiz
